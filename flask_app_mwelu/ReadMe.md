# Flask App README

Follow these steps to run the Flask app on the server:

- Use Jupyter Terminal (or another terminal of your choice) to change the directory to `flask_app`.
- Run the app using the following command:
  ```bash
  python -m flask run --host=0.0.0.0
```
- Ensure that port 5000 is open on the server and in the cloud firewall. The server IP is assumed to be 34.121.212.193.

- To test the app, follow these steps:

    * Open test.html in a browser on your local computer.
    * Submit a .jpg file using the provided form.
