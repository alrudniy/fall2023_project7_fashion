# React Native App README

Follow these steps to run the React Native app on a phone:

- In VSCode terminal, change directory to csci340-app
- Run the app using the following command:
```bash
  npx expo start
```
- Scan the QR code 
  * Android: with ExpoGo app on your phone.
  * iOS: with the Camera app. ExpoGo app must be installed on your phone.
